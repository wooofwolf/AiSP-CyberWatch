
# AiSP: CyberWatch

**AiSP: CyberWatch** is an educational game developed using Unity to deliver cybersecurity-related learning experiences through interactive gameplay and minigames.

The project was developed collaboratively by a team of two programmers and three artists based on client requirements.

## My Contributions

- Designed and implemented gameplay mechanics for two educational minigames using Unity.
- Implemented object pooling to manage reusable game objects.
- Developed finite state machines to organise gameplay behaviour.
- Implemented persistent high-score storage.
- Developed a dialogue system for in-game interactions.

## Project Outcome

- Contributed to two of the four minigames featured in the final product.
- Successfully delivered the project to the client on schedule.
- The completed game was showcased at the **AiSP Youth Symposium 2022**.
